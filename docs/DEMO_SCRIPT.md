# Demo script — Carrot Midnight (≈ 3–4 minutes)

## Setup

1. Open https://carrot-midnight.vercel.app **or** `npm run dev`.
2. Mention: Compact compiles (**9 circuits**); **local demo is first-class**; **Preprod** is the live Wave 1 network with a deployed contract.

## Beat-by-beat

1. **Welcome (15s)** — Brand splash, network pill, sound toggle, live-requirements hint (Lace/1AM · :6300 · faucet). Click **Enter the Game**.

2. **Lobby (25s)** — Game floor + wager presets. Create an open game.  
   Say: “Location committed publicly as a hash; value stays private.”

3. **Invite multi-tab (20s)** — Room shows **JOIN CODE**. Open second tab → Player B.

4. **Roles + peek (25s)** — Act as A → tap **your box** for private peek. “No public ledger write.”

5. **Accept + deadline (25s)** — Accept as B. Show decision countdown. Chat unlocks.

6. **Chat (20s)** — Send a bluff: AES-GCM; hash mirrors Compact `postChatCiphertext`.

7. **Decision → settle (40s)** — B **Keep** or **Swap** → **Settle** — result modal + pot.

8. **History (15s)** — Dock **HISTORY**.

9. **Connection / Preprod (30s)** — Dock **SETTINGS** → toggle **PREPROD**. Show Wave 1 **contract address** + requirements (Lace/1AM, proof `:6300`, faucet). Flash Compact + artifact path.

10. **Close (10s)** — Hard gate: Compact + demo + Preprod evidence. Video recording uses this script.
